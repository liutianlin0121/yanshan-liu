# 才元刘氏先世著作

直隶盐山县才元刘氏先人著作的阅读网页：原书影印、标点原文与白话逐句对照。

- `lifeng/` 《蒞鳳簡言》刘泽霖公 撰（康熙四年序，道光十三年重镌本）
- `zhuan/` 《高城劉蔭渠先生傳》刘曾璈公 撰（道光二十六年刻本）
- `xingshu/` 《鹽山劉蔭渠公行述》刘庆元公、刘庆凯公 撰（道光二十六年刻本）
- `chunqiu/` 《春秋書法比義》
- `lianchuang/` 《蓮窗書室詩鈔》刘曾璇公 撰
- `qieshan/` 《篋山詩草》刘曰萼公 撰
- `huainan/` 《槐南書屋詩稿》刘庆凯公 撰
- `search/` 全站搜索；`shumu/` 待查书目；`huaxu/` 整理花絮；`about/` 整理者；`pdf/` 原书影印

各书页面由整理工程中的 `build_*.py --publish` 生成，`search/index.json` 由 `build_search.py` 生成，`huaxu/` 由 `huaxu/build.py --publish` 生成，这些不要手改。首页 `index.html`、`shumu/`、`search/index.html` 是手写的。

录文、标点、白话与注释由才元刘氏廿二世天霖在 Claude 协助下完成，难免有误，欢迎指正。
